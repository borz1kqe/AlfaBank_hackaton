# 🅰️ Альфа-Инсайт: Персонализированная новостная аналитика для крупного бизнеса в ИБ «Альфа-Бизнес»

Решение кейса Альфа-Банка **«Новостная аналитика для принятия бизнес-решений»**.  
Сервис превращает поток внешних новостей и аналитических отчетов Центра макроэкономических исследований (ЦМИ) Альфа-Банка в персонализированные бизнес-инсайты для руководителей крупного бизнеса (выручка > 15 млрд ₽) с учетом цифрового профиля компании, графа контрагентов и роли ЛПР.

> **Доступ для жюри:** Репозиторий открыт / предоставлен доступ аккаунту `alfa-hack-2026`.

---
